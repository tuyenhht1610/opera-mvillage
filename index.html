Dữ liệu
Profile data từ Odoo thiếu nhiều field Opera cần — profile type, market segment. Opera phân 3 loại: Individual / Company / Travel Agent. Cần 3 bên Sales · Finance · Tech thống nhất — đây là master data toàn hệ thống.
Booking history Odoo khác Opera — cần migration để xử lý past stay history. Quan trọng cho Loyalty Engine tính tier chính xác.
Báo cáo Looker Studio đang dùng Odoo làm data source — cần rebuild data warehouse từ Opera + Fast ERP. Cần đánh giá latency → giao Engineering xử lý.
